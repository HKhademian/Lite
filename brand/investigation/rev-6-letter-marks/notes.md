# Revision 6: letter marks

Working sketches, not a selected identity. Each standalone mark is reused without redrawing as the first character of the studio wordmark. The spark in candidate 05 also serves as the dot of the i.

- 01: Upright feather spine and three small barbs.
- 02: Narrow open feather around an L.
- 03: Slanted feather L.
- 04: Kinked lightning L.
- 05: L and spark / li.
- 06: Three-barb quill with an L foot.

The letter read, feather details, wordmark spacing, and 16 px rendering all need visual judgment. Letter case in this revision keeps the same first glyph in both studio modes.
