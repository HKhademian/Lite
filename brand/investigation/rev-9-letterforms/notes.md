# Revision 9: letterform studies

Creator: `gpt-6.1-terra`.

Working sketches for a mark that reads as l or L and is reused as the first letter of lite. Letterform inspiration: [Wiktionary: Variations of “l”](https://en.wiktionary.org/wiki/Appendix:Variations_of_%22l%22), including the script ℓ and ℒ, slashed ł, curled ȴ, and double-struck 𝕃. The marks are original vector sketches rather than font glyphs.

| Ref | Candidate | Investigation |
| --- | --- | --- |
| R9-01 | [Looped l](01-looped-l.svg) | A simple looped ascender inspired by ℓ. |
| R9-02 | [Open script l](02-open-script-l.svg) | A lighter ℓ with an open shoulder and a curled base. |
| R9-03 | [Script capital L](03-script-capital-l.svg) | A single flowing L with a top entry loop and broad foot, inspired by ℒ. |
| R9-04 | [Ribbon l](04-ribbon-l.svg) | A looped l with a narrow crossing, inspired by script and curled l forms. |
| R9-05 | [Slashed l](05-slashed-l.svg) | A rounded l with one diagonal stroke, inspired by ł. |
| R9-06 | [Curled l](06-curl-l.svg) | A minimal stem ending in a small curl, inspired by ȴ. |
| R9-07 | [Double-line L](07-double-line-l.svg) | An L with a slender parallel stroke, inspired by double-struck 𝕃. |
| R9-08 | [Feather script l](08-feather-script-l.svg) | A looped ℓ with two delicate feather strokes. |

All marks use the exact same SVG paths as their wordmark first letter. The studio presents them at 16 px, on light and dark backgrounds, and in a wordmark. These are studies: reading as l, spacing, and small-size rendering need visual review.
