# Longest Substring Without Repeating Characters

**Source:** [LeetCode #3](https://leetcode.com/problems/longest-substring-without-repeating-characters/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** hash-table, strings, sliding-window  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given a string s, find the length of the longest substring without duplicate characters.

## Public examples

### example-1

```text
Input: s = "abcabcbb"
Output: 3
```
