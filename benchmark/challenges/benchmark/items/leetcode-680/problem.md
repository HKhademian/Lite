# Valid Palindrome II

**Source:** [LeetCode #680](https://leetcode.com/problems/valid-palindrome-ii/)  
**Difficulty:** 2.0/10 (Easy)  
**Topics:** two-pointers, strings, greedy  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given a string s, return true if the s can be palindrome after deleting at most one character from it.

## Public examples

### example-1

```text
Input: s = "aba"
Output: true
```
