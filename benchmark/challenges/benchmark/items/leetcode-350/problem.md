# Intersection of Two Arrays II

**Source:** [LeetCode #350](https://leetcode.com/problems/intersection-of-two-arrays-ii/)  
**Difficulty:** 2.0/10 (Easy)  
**Topics:** arrays, hash-table, two-pointers, binary-search, sorting  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given two integer arrays nums1 and nums2, return an array of their intersection. Each element in the result must appear as many times as it shows in both arrays and you may return the result in any order.

## Public examples

### example-1

```text
Input: nums1 = [1,2,2,1], nums2 = [2,2]
Output: [2,2]
```
