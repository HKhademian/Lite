# Perfect Square Collection

**Source:** [Project Euler #142](https://projecteuler.net/problem=142)  
**Answer type:** one number  
**Difficulty:** 4.0/10 (142)

## Problem

Find the smallest $x + y + z$ with integers $x \gt y \gt z \gt 0$ such that $x + y$, $x - y$, $x + z$, $x - z$, $y + z$, $y - z$ are all perfect squares.

## Output

Print the single numeric answer.
