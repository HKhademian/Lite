# Missing Number

**Source:** [LeetCode #268](https://leetcode.com/problems/missing-number/)  
**Difficulty:** 2.0/10 (Easy)  
**Topics:** arrays, hash-table, math, binary-search, bit-manipulation, sorting  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given an array nums containing n distinct numbers in the range [0, n], return the only number in the range that is missing from the array.

## Public examples

### example-1

```text
Input: nums = [3,0,1]
Output: 2
```
