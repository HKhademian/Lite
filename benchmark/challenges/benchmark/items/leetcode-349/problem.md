# Intersection of Two Arrays

**Source:** [LeetCode #349](https://leetcode.com/problems/intersection-of-two-arrays/)  
**Difficulty:** 2.0/10 (Easy)  
**Topics:** arrays, hash-table, two-pointers, binary-search, sorting  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given two integer arrays nums1 and nums2, return an array of their intersection. Each element in the result must be unique and you may return the result in any order.

## Public examples

### example-1

```text
Input: nums1 = [1,2,2,1], nums2 = [2,2]
Output: [2]
```
