# Trapping Rain Water

**Source:** [LeetCode #42](https://leetcode.com/problems/trapping-rain-water/)  
**Difficulty:** 8.0/10 (Hard)  
**Topics:** arrays, two-pointers, dynamic-programming, stack, monotonic-stack  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given n non-negative integers representing an elevation map where the width of each bar is 1, compute how much water it can trap after raining.

## Public examples

### example-1

```text
Input: height = [0,1,0,2,1,0,1,3,2,1,2,1]
Output: 6
```
