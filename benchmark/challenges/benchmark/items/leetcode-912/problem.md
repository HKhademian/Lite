# Sort an Array

**Source:** [LeetCode #912](https://leetcode.com/problems/sort-an-array/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** arrays, divide-and-conquer, sorting, heap, merge-sort, bucket-sort, radix-sort, counting-sort  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given an array of integers nums, sort the array in ascending order and return it.
You must solve the problem without using any built-in functions in O(nlog(n)) time complexity and with the smallest space complexity possible.

## Public examples

### example-1

```text
Input: nums = [5,2,3,1]
Output: [1,2,3,5]
```
