# Add Binary

**Source:** [LeetCode #67](https://leetcode.com/problems/add-binary/)  
**Difficulty:** 2.0/10 (Easy)  
**Topics:** math, strings, bit-manipulation, simulation  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given two binary strings a and b, return their sum as a binary string.

## Public examples

### example-1

```text
Input: a = "11", b = "1"
Output: "100"
```
