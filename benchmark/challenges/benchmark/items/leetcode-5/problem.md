# Longest Palindromic Substring

**Source:** [LeetCode #5](https://leetcode.com/problems/longest-palindromic-substring/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** two-pointers, strings, dynamic-programming  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given a string s, return the longest palindromic substring in s.

## Public examples

### example-1

```text
Input: s = "babad"
Output: "bab"
```
