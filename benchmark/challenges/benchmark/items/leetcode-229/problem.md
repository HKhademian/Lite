# Majority Element II

**Source:** [LeetCode #229](https://leetcode.com/problems/majority-element-ii/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** arrays, hash-table, sorting, counting  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given an integer array of size n, find all elements that appear more than ⌊ n/3 ⌋ times.

## Public examples

### example-1

```text
Input: nums = [3,2,3]
Output: [3]
```
