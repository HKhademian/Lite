# Unique Binary Search Trees

**Source:** [LeetCode #96](https://leetcode.com/problems/unique-binary-search-trees/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** math, dynamic-programming, trees, binary-search-tree, binary-tree  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given an integer n, return the number of structurally unique BST's (binary search trees) which has exactly n nodes of unique values from 1 to n.

## Public examples

### example-1

```text
Input: n = 3
Output: 5
```
