# Kth Largest Element in an Array

**Source:** [LeetCode #215](https://leetcode.com/problems/kth-largest-element-in-an-array/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** arrays, divide-and-conquer, sorting, heap, quickselect  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given an integer array nums and an integer k, return the kth largest element in the array.
Note that it is the kth largest element in the sorted order, not the kth distinct element.
Can you solve it without sorting?

## Public examples

### example-1

```text
Input: nums = [3,2,1,5,6,4], k = 2
Output: 5
```
