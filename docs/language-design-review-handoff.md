The guaranteed contract is the statically known input tuple shape; supplied arguments must provably satisfy its required fixed slots, routing, final-slot types, and access permissions. Runtime tail length does not change tuple shape. Both max(...fixed, ...extra) and max(...extra, ...fixed,) are valid for Int sources when fixed: [Int; 5] proves sufficient total length for the two required inputs. Route the composed positional sequence in written order; the leading runtime spread can supply fixed-slot values when all possible types/access are compatible. Value origins may vary with runtime length; input tuple shape does not. Reject unproven fixed coverage without a runtime arity fallback. Documentation/formatter clarification, 2026-10-24: omit unnecessary semicolons after complete block/record items everywhere, including nested definitions and braced initializers. Keep ordinary adjacent-item separators, enclosing call/list punctuation, import-list separators, and any separately identified special delimiter. Continue LiteScript's type-safe scripting-language design in `docs/`.
