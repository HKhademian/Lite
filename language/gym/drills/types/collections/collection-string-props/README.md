# Collection & String Metadata Properties

Read a line `word`, an integer `n`, and `n` tag strings. Store all tags in a `List<String>` and unique tags in a `Set<String>`, then print:

```text
<word.length> <word.isEmpty> <tags.length> <unique.size> <unique.isEmpty>
```

## Requirements

- Use `.length` and `.isEmpty` on `String` and `List<String>`.
- Use `.size` and `.isEmpty` on `Set<String>`.
