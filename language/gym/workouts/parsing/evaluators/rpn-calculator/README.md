# Workout: Reverse Polish Notation (RPN) Evaluator

Read one line of whitespace-separated Reverse Polish Notation tokens supporting signed integers and binary operators `+`, `-`, `*`, `/` (truncating integer division).
- If valid and leaving exactly one value on the stack, print that integer.
- Print `"ERR"` on empty input, stack underflow, unknown tokens, division by zero, or leftover operands on the stack.
