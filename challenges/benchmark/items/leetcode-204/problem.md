# Count Primes

**Source:** [LeetCode #204](https://leetcode.com/problems/count-primes/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** arrays, math, enumeration, number-theory  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given an integer n, return the number of prime numbers that are strictly less than n.

## Public examples

### example-1

```text
Input: n = 10
Output: 4
```
