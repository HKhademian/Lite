# Convert Sorted Array to Binary Search Tree

**Source:** [LeetCode #108](https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/)  
**Difficulty:** 2.0/10 (Easy)  
**Topics:** arrays, divide-and-conquer, trees, binary-search-tree, binary-tree  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given an integer array nums where the elements are sorted in ascending order, convert it to a height-balanced binary search tree.

## Public examples

### example-1

```text
Input: nums = [-10,-3,0,5,9]
Output: [0,-3,9,-10,null,5]
```
