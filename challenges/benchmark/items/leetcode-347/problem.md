# Top K Frequent Elements

**Source:** [LeetCode #347](https://leetcode.com/problems/top-k-frequent-elements/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** arrays, hash-table, divide-and-conquer, sorting, heap, bucket-sort, counting, quickselect  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given an integer array nums and an integer k, return the k most frequent elements. You may return the answer in any order.

## Public examples

### example-1

```text
Input: nums = [1,1,1,2,2,3], k = 2
Output: [1,2]
```
