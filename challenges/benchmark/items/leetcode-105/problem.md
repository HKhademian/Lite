# Construct Binary Tree from Preorder and Inorder Traversal

**Source:** [LeetCode #105](https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)  
**Difficulty:** 5.0/10 (Medium)  
**Topics:** arrays, hash-table, divide-and-conquer, trees, binary-tree  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given two integer arrays preorder and inorder where preorder is the preorder traversal of a binary tree and inorder is the inorder traversal of the same tree, construct and return the binary tree.

## Public examples

### example-1

```text
Input: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
Output: [3,9,20,null,null,15,7]
```
