# Find the Index of the First Occurrence in a String

**Source:** [LeetCode #28](https://leetcode.com/problems/find-the-index-of-the-first-occurrence-in-a-string/)  
**Difficulty:** 2.0/10 (Easy)  
**Topics:** two-pointers, strings, string-matching  
**Harness:** function-style inputs (`name = value` pairs)

## Problem

Given two strings needle and haystack, return the index of the first occurrence of needle in haystack, or -1 if needle is not part of haystack.

## Public examples

### example-1

```text
Input: haystack = "sadbutsad", needle = "sad"
Output: 0
```
